# 🖥️ Fila Zero — Front-End

Interface web do sistema **Fila Zero**, desenvolvida para permitir que cidadãos e servidores realizem, consultem, reagendem e cancelem atendimentos públicos de forma rápida e responsiva.

---

## 🛠️ Tecnologias Utilizadas

* **React 19** + **Vite**
* **Tailwind CSS** (estilização e layout responsivo)
* **React Router DOM 7** (gerenciamento de rotas)
* **Lucide React Icons** (ícones da interface)

---

## 🚀 Como Executar o Front-End

```bash
# 1. Instale as dependências
npm install

# 2. Inicie o servidor de desenvolvimento
npm run dev
